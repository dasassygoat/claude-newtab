How to get a client ID (one-time, ~3 minutes in Entra admin center)
  1. Go to Entra → App registrations → New registration.
  2. Name: Claude New Tab. Supported account types: Accounts in this organizational directory only (or multi-tenant if you have several).
  3. Redirect URI: platform Single-page application (SPA), URI
  4. Register. Copy the Application (client) ID into the box above.
  5. API permissions → Add → Microsoft Graph → Delegated → Calendars.Read (and User.Read). Grant admin consent if prompted.
  6. Click Sign in with Microsoft above.

iCal (.ics) feeds

Works with any published/secret iCal URL: Outlook (Settings → Calendar → Shared calendars → Publish a calendar → ICS), Google Calendar (Settings → your calendar → Secret address in iCal format), iCloud, etc. Outlook's published feeds can lag by a few hours; use Microsoft sign-in above for live data.

Quick prompts

One per line as Label | Prompt text. A prompt ending in : or ? is treated as a prefix and placed in the box for you to finish. Use __PLAN_DAY__ for the built-in "plan my day" prompt that includes today's calendar.
